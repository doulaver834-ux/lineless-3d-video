# 高质量交付标准（Quality Bar）

来源：2026-11-24 同一题材两次重制的对照教训（本机项目路径见 `LOCAL.md`）。
- **被否决版**：单个场景、沿用上一版切好的原声、单线程搭景，一个场景文件扛全片。评价「完全没有第一版好，差距很大」。
- **被认可版**：49.10s，4 座场景、12 镜，4 个场景 Subagent 并行精雕，场景代码约 8,466 行。

用户的原话标准是「**细致、高质量，我不要看 demo**」。以下各条为硬性要求，不是建议。

---

## 一、开工前：不要沿用低质量的上游素材

1. 用户说「重新做」时，**不要复用上一版的切音、单房间场景代码或站位**，从剧本重新开始。
2. 被否决版本的项目目录只能拿来查坐标和 bug，不能当新版的起点。
3. 叙事形式（专业旁白 vs 现场原声）先用一个问题问清楚再开工，不要自行假设。

## 二、空间与镜头密度

| 指标 | 最低要求（短片 30–60s） |
| --- | --- |
| 独立三维场景 | ≥ 3 座（认可版是 4 座：室内暮色、室外晨光、挑高中庭、实验室），冷暖光与昼夜要有对比 |
| 镜头数 | 每 4–6 秒换一次空间或机位，60 秒内 ≥ 10 镜 |
| 单场景代码量 | 每座场景单独一个 `setXxx3d.ts`，**≥ 650 行**（认可版 1,700–2,500 行/座）；不允许一个文件塞全片 |
| 每座场景的必备层次 | 前景（过肩人物/道具虚化）+ 中景主体 + 真实三维门窗开口外的远景（多层山体/楼宇/天空） |
| 道具叙事 | 每座场景至少 1 件随剧情动画的英雄道具（例：滑过桌面的辞职卷宗、锁进玻璃柜的皮衣、自动开启的玻璃门、升起旋转的显卡），由 `state` 中 0..1 的进度值驱动 |

**明确禁止**：白墙空房间、一字排开的人群、大面积纯色无纹理地面、整片只靠同一张底图推拉。

## 三、表面细节（每座场景都要有）

- 程序化手绘纹理（`rawCtex` / `rawRep`）：木纹拼花地板、地毯/地垫、石材接缝、书脊、装裱图纸，**不画黑色描边**。
- 墙脚和重家具底部加暖褐 AO 条；高顶棚 `castShadow = false`，让平行光照进室内。
- 体积光束 + 地面光斑 + 极小浮尘（`0.006–0.007m`，`opacity ≤ 0.24`）。
- 发光源（台灯、LED、屏幕、窗外灯火）用 `MeshBasicMaterial` + `NOINK`，配合 Bloom。
- CC0 `.glb` 家具/植物只作陪衬填充（认可版每座 1–12 件），**主体建筑和英雄道具必须手工建模**，不能全靠资产库拼。
- 可直接复用的工具函数（`addAOStrip`、`addVolumetricSunbeam`、`addSunPool`、`createDustMotes`、`makeWoodPlankTex`）见 `examples/benchmark_1876_3d/interiors3d.ts`。

## 四、角色

- 群演按真实 Z 轴错落分布在不同高度（楼梯、回廊、前后排），不要等距横排。
- 双人拥抱用等比例的专用拥抱骨骼（`standingHug` / `createHugActor`），不要把一个人的头缩小贴在另一个人胸口。
- 正面手臂 IK 要让肘部朝外；说话口型要张得开、看得出来。
- 当代题材要配专用服装 kit（西装、工牌、卫衣、马甲等），不要拿历史服装凑合。

## 五、多 Subagent 并行精雕流程（短片也要用）

1. **主线程先锁定**：剧本 → 配音 → `words.json` → 镜头表（`director.ts` 里每镜的 `t0/t1`、机位、焦距、光圈）→ 每座场景的**世界坐标契约**（桌面高度、人物站位、要留空的走道区域、英雄道具位置）。
2. **定义一个专用场景建筑师 subagent**，系统提示里写死第一节「画风铁律」（零黑描边、`twoTone`、`rawCtex`、高顶棚不投影、AO 条与体积光、确定性随机数 `mulberry32`、只按 `state.t` 计算变换、`tsc --noEmit` 零报错）。
3. **每座场景派一个 subagent**，任务书必须包含：
   - 唯一可写文件（「只写 `src/setXxx3d.ts`，不改其他文件」），避免并行写冲突；
   - 精确的 TypeScript 接口（`createXxx3D()` 返回 `{root, readyPromise, update(state)}`，`state` 含英雄道具的 0..1 进度值）；
   - 房间尺寸、关键物体的世界坐标与高度、必须留空的区域；
   - 先读的参考文件（`examples/benchmark_1876_3d/interiors3d.ts` 前 320 行）；
   - 行数下限（650–1,050 行）和「交稿时汇报关键坐标」。
4. 角色骨骼/服装/道具的改动单独交给一个 subagent（独占 `style2Rig.js` + `linelessCast.ts`）。
5. 主线程在 subagent 工作期间同时做主合成、运镜和拟音，全部交稿后再统一质检。

## 六、交付前质检

- 必须跑 `--stills` 出全片每镜关键帧联排图，按 `architecture-and-craft.md` 的 10 项质检表逐张核对，修完再渲染 2K。
- 自检时把新成片和认可基准（`examples/benchmark_1876_3d/`，以及 `LOCAL.md` 中登记的认可短片联排图）**并排对比**，任何一镜的细节密度明显低于基准就返工，不交付。
- 汇报时写清楚：用了几座场景、多少镜、哪些英雄道具、质检修了什么。
